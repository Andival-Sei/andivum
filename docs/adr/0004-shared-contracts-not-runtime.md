# ADR 0004: Общие контракты вместо общего клиентского runtime

- Статус: принято
- Дата: 2026-08-02

## Контекст

Клиенты используют разные нативные языки, но должны одинаково понимать данные и
бизнес-правила.

## Решение

Общими являются OpenAPI/JSON schemas, сгенерированные модели, серверные
инварианты и golden test cases. Общий Rust/Wasm/C++ runtime на старте не
добавляется.

## Последствия

Некоторые проверки и offline-use cases реализуются дважды. Это проще отлаживать,
чем FFI и третий toolchain. Решение может быть пересмотрено после профилирования
реально крупного чистого algorithmic core.
