# ADR 0005: Display name отделён от технической идентичности

- Статус: принято
- Дата: 2026-08-02

## Контекст

Рабочее название может измениться, но package IDs и passkey domain после
публикации имеют строгую идентичность.

## Решение

`config/product.json` хранит display name и связанные product settings.
Генераторы переносят их в ресурсы платформ. Технические IDs хранятся рядом, но
меняются только через миграционный ADR.

## Последствия

Обычный ребрендинг не требует поиска литералов по коду. До первого production
auth и публикации необходимо окончательно закрепить домен и package identities.
