# ADR 0002: Modular monolith backend

- Статус: принято
- Дата: 2026-08-02

## Контекст

У продукта будет много связанных модулей, но начальная команда и нагрузка не
оправдывают распределённую систему.

## Решение

Backend создаётся как один deployable ASP.NET Core modular monolith. Identity,
Tasks, Finance, Integrations и Automation имеют явные границы, собственные
данные и контракты.

## Последствия

Локальная разработка и транзакции остаются простыми. Модуль можно выделить в
отдельный сервис позже, если граница подтверждена профилированием или
эксплуатацией.
