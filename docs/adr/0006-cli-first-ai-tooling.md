# ADR 0006: CLI-first интерфейс для AI и автоматизации

- Статус: принято
- Дата: 2026-08-02

## Контекст

AI-агенту нужны воспроизводимые способы собирать, тестировать, запускать и
диагностировать систему. Встроенный production MCP создал бы лишнюю поверхность
атаки.

## Решение

Сначала создаётся developer CLI и корневой `pnpm` facade со стабильными exit
codes и `--json`. MCP при необходимости становится отдельным development-only
адаптером над CLI/application services.

## Последствия

Одни команды подходят людям, CI и агентам. Production-приложения не содержат
административный MCP endpoint или прямой доступ к базе.
