# ADR 0001: Два нативных платформенных клиента

- Статус: принято
- Дата: 2026-08-02

## Контекст

Приложению нужны высокая отзывчивость, естественный UX и полный доступ к
возможностям Windows 11 и Android.

## Решение

Windows-клиент создаётся на C#/.NET/WinUI 3, Android-клиент — на Kotlin/Jetpack
Compose. Cross-platform UI frameworks не используются.

## Последствия

Платформенный код и часть клиентской логики будут дублироваться. Взамен каждая
платформа получает нативный lifecycle, UI, accessibility, фоновые задачи,
уведомления и credential APIs без промежуточного runtime.
