# ADR 0007: Автономная spec-first TDD-разработка

- Статус: принято
- Дата: 2026-08-02

## Контекст

Владелец Andivum формулирует продуктовые желания, но не пишет код и не хочет
диспетчеризировать каждое инженерное действие.

## Решение

AI-агент автономно ведёт цикл intent → spec → plan → TDD → review → QA → CI →
delivery. Рутинные подтверждения не требуются. Для production-поведения
обязателен Red-Green-Refactor; для security-critical областей добавляется
отдельный security review.

## Последствия

Разработка не зависит от ручной инженерной работы владельца и сохраняет
аудируемую историю решений. Цена — постоянное ведение spec/plan/test артефактов.
Пауза сохраняется только для недоступных полномочий, секретов, платежей,
юридических решений и труднообратимых внешних действий.
