# Восстановление Android-входа после незавершённого callback

## Проблема

После возврата из системного браузера или перезапуска приложения Android мог
остаться на экране ожидания входа. Незавершённое состояние Auth0 сохранялось
раньше, чем становился известен результат обмена кода, а экран не предлагал
восстановиться без очистки данных приложения.

## Наблюдаемое поведение после исправления

- состояние сохраняется только после успешного обмена authorization code на
  токены;
- ошибка callback, обмена или обновления сессии очищает незавершённое локальное
  состояние;
- пока приложение ждёт браузер или проверяет сохранённую сессию, доступна
  кнопка «Вернуться ко входу»;
- после отмены экран снова позволяет начать вход;
- callback зарегистрирован только для `andivum://android/auth/callback`.

## Ограничения

Кнопка отмены удаляет только локальное зашифрованное состояние Andivum на
устройстве. Аккаунт Auth0 и данные Supabase не удаляются.

## Проверки

- Node-регрессия проверяет callback, очистку состояния и кнопку восстановления;
- Android instrumentation проверяет переход busy → sign-in;
- cloud APK собирается и устанавливается на физический Pixel 7 Pro;
- callback receiver проверяется в merged Android manifest.
