# Тестирование Andivum

## Локальный smoke-аккаунт

Для реальной проверки регистрации, входа, сессии и защищённых запросов
используются локальные данные из файла `.env.andivum.test.local` в корне
репозитория.

Файл намеренно не входит в Git: правило `.env.*` в `.gitignore` исключает его
из отслеживания. Значения из него нельзя копировать в документацию, журнал
разработки, issue, commit, логи или сообщения владельцу проекта.

AI-агент может прочитать этот файл непосредственно перед smoke-тестом и
передать данные только в форму тестируемого приложения или в локальный
тестовый запрос. После теста значения не должны появляться в выводе команд.

Тестовый аккаунт предназначен только для разработки. В нём нельзя хранить
реальные пользовательские данные, финансовую информацию или production-секреты.
Если пароль меняется, обновляется только локальный файл и соответствующая
учётная запись в Supabase Dashboard; пароль не записывается в Git.

## Минимальный auth smoke

1. Собрать cloud-конфигурацию клиента.
2. Ввести email и пароль из `.env.andivum.test.local` в нативном интерфейсе.
3. Убедиться, что сервер подтвердил аккаунт и открыл dashboard.
4. Перезапустить Windows и Android-клиенты и проверить восстановление сессии.
5. Проверить защищённый запрос профиля без вывода токенов.

После любого сбоя записать симптом, причину, исправление и регрессионную
проверку в `docs/DEVELOPMENT_LOG.md`.
