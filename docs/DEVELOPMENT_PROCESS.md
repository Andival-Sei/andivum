# Процесс разработки

Andivum разрабатывается автономным AI-агентом под продуктовым руководством
владельца. Полный design rationale зафиксирован в
[`docs/superpowers/specs/2026-08-02-autonomous-development-design.md`](superpowers/specs/2026-08-02-autonomous-development-design.md).

## Главный принцип

Владелец говорит, какой результат ему нужен. Агент самостоятельно проходит путь
от требования до проверенного изменения в GitHub. Рутинные промежуточные
согласования не требуются.

```text
Intent → Context → Spec → Plan → RED → GREEN → REFACTOR
       → Review → Platform QA → CI → Delivery → Documentation
```

## Масштаб процесса

### Малое механическое изменение

Для опечатки, форматирования или очевидной конфигурации достаточно короткого
плана в рабочем контексте, релевантной проверки и отдельного commit.

### Обычная feature или bugfix

- spec с наблюдаемым поведением;
- implementation plan;
- TDD;
- code review;
- проверки затронутых платформ;
- commit, push и CI.

### Архитектура, auth, финансы, sync и интеграции

Дополнительно обязательны ADR, threat/security review, integration tests и
проверка отказов/восстановления.

## Ветки и доставка

- Foundation допускает прямые документальные commits в `main`.
- Production features выполняются в `agent/<short-description>`.
- Крупные планы могут использовать отдельный Git worktree.
- После зелёных тестов и review создаётся PR.
- При зелёном обязательном CI агент может самостоятельно merge PR.
- Один commit/PR не смешивает независимые изменения.

## Когда агент задаёт вопрос

Вопрос задаётся только если разумное допущение заметно изменит пользовательский
результат или необходимы недоступные данные/полномочия. В остальных случаях
агент выбирает безопасный минимальный вариант, фиксирует допущение и продолжает.

## Команды качества

Корневой `pnpm` остаётся единым интерфейсом:

```powershell
pnpm doctor
pnpm check
pnpm test
pnpm build
```

Команды появляются по мере появления соответствующих проектов. Они обязаны быть
пригодны для человека, AI и CI и возвращать корректный exit code.
