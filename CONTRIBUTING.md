# Участие в разработке

Проект находится на ранней стадии. Перед изменениями прочитайте `AGENTS.md` и
документы, на которые он ссылается.

## Локальные правила

```powershell
pnpm install
pnpm check
```

- Не коммитьте секреты и локальные signing artifacts.
- Не меняйте принятые архитектурные решения без нового ADR.
- Используйте Conventional Commits на русском языке.
- Отделяйте рефакторинг от изменения поведения.
- В PR указывайте, какие проверки были выполнены фактически.

Пока лицензия не выбрана, значительные внешние contributions лучше заранее
согласовать в GitHub Issue.
