# Политика безопасности

Публичный issue не подходит для сообщения об уязвимости, содержащего
эксплуатационные детали или реальные пользовательские данные. До настройки
отдельного security contact используйте GitHub Private Vulnerability Reporting,
если эта возможность включена для репозитория.

Никогда не прикладывайте:

- пароли, passkeys, private keys и recovery codes;
- access/refresh tokens;
- OAuth client secrets;
- production database dumps;
- персональные финансовые данные.

Проект находится на pre-release стадии; поддерживаемых production-версий пока
нет.
